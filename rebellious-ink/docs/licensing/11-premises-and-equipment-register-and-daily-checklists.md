## 10. Daily opening checklist

Date: ______________ Completed by: ______________

- [ ] Premises secure and undamaged on arrival
- [ ] Ventilation on, windows opened where suitable
- [ ] Hand-wash basins working: hot and cold water, soap, paper towels stocked
- [ ] Treatment area surfaces wiped with disinfectant
- [ ] Paper sheets, barrier film, gloves, aprons and sterile stock in date and available
- [ ] Sharps bins fitted, below the fill line, and correctly labelled
- [ ] Clinical waste bins lined, foot-operated and working
- [ ] Spillage kit and first aid kit in place
- [ ] Autoclave and ultrasonic cleaner checks done and logged (only if used)
- [ ] "No Smoking" and "No Eating or Drinking" notices displayed
- [ ] Certificates and byelaws displayed
- [ ] Consent forms, aftercare sheets and ID check records ready
- [ ] Fire exits clear, extinguishers in place
- [ ] Any faults or issues noted: ______________________________________

## 11. Daily closing checklist

Date: ______________ Completed by: ______________

- [ ] All sharps in bins, no loose sharps anywhere
- [ ] Sharps bins closed temporarily, none above the fill line
- [ ] Clinical waste bagged, labelled and moved to the clinical waste store, store locked
- [ ] All couches, chairs, stools, trays and work surfaces cleaned and disinfected
- [ ] Treatment area floor washed and disinfected
- [ ] Hand-wash basins, sinks and sanitary accommodation cleaned
- [ ] Reusable items reprocessed and logged (only if used)
- [ ] Sterile stock returned to closed storage
- [ ] Ink put away, caps closed, bottle tips wiped
- [ ] Cloth items for laundry put in a laundry bag
- [ ] Client records locked away or logged out
- [ ] Cleaning log completed
- [ ] Equipment switched off, kettles and heaters off
- [ ] Windows closed, doors and storage locked, alarm set
- [ ] Any incidents or near misses logged: ____________________________
